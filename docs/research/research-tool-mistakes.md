# Mistakes to avoid / problems to solve: register from existing Xcode build-analysis tools

Compiled 2026-10-30. Sources: GitHub issue/PR pages fetched via WebFetch (about 75 individual issues/PRs read; list pages for all tools). Page contents were summarized by a fast model, so quotes marked "quote" are as relayed and should be re-verified before external citation. Cat = category 1-8 from the brief (1 compat, 2 wrong data, 3 usability, 4 perf, 5 correctness of target kinds, 6 abandoned request, 7 privacy, 8 project editing).

Base URLs: XLP = https://github.com/MobileNativeFoundation/XCLogParser ; XCM = https://github.com/spotify/XCMetrics ; BTA = https://github.com/RobertGummesson/BuildTimeAnalyzer-for-Xcode ; XCP = https://github.com/giginet/xcprofiler ; XBR = https://github.com/PaulTaykalo/xcode-build-times-rendering ; XPJ = https://github.com/tuist/XcodeProj ; TU = https://github.com/tuist/tuist ; XRC = https://github.com/spotify/xcremotecache
